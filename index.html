炭酸を、なるべく速く、こぼさずに。

  • 押したまま(ドラッグ)でボトルとグラスを持ちます。離すと両方とも元に戻ります。
  • 上下: ボトルの傾き(上ほど勢いよく注ぐ)。左右: グラスの傾き(右ほどボトル側へ傾く)。
  • ホイール(または右のスライダー): 注ぎ口の高さ。高いほど液柱が速く突っ込み、空気を巻き込みます。
  • 液体が目標線に届いた時点でタイム確定。泡が落ち着くまで見届けて、こぼれた量を集計します。
  • 記録 = タイム + こぼした液 1 mL ごとに 0.5 秒。キーボード: R でやり直し、Space で押したまま、矢印で操作。

水で操作に慣れましょう

  1. 上にドラッグするとボトルが傾いて注ぎ始めます。下へ戻すと弱まります。
  2. 右にドラッグするとグラスがボトル側へ傾きます。
  3. ホイール(または右の「注ぎ口の高さ」)で注ぎ口を上げ下げします。
  4. 液が目標線に届いた時点でタイムが決まります。指を離すとボトルもグラスも元に戻ります。こぼした液は 1 mL ごとに 0.5 秒の加算です。
